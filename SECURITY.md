# Security Policy

## Supported Versions

We provide security updates for the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in this project (particularly anything regarding local filesystem access, arbitrary code execution, or unintended data exposure):

1. **Do NOT open a public issue.**
2. Report the vulnerability privately via **GitHub Security Advisories**:
   - Navigate to the repository's **Security** tab.
   - Click **"Report a vulnerability"** to open a private advisory draft.
3. If GitHub Security Advisories are unavailable, contact the project maintainers directly through their GitHub profile.

Please include:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction steps or a minimal proof-of-concept.
- Suggestions on how to remediate the issue, if available.

We will review reports promptly, coordinate a fix, and acknowledge your contribution in the release notes.
