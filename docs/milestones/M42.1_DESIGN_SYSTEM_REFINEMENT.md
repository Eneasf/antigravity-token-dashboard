# Milestone 42.1: Design System Deep Refinement & Bug Fixes

**Active Branch**: `feat/m42.1-design-system-fixes`  
**Standard**: Done if proven, not if declared (`AGENTS.md` §3 & `vdone`)

---

## 1. Context & Architectural Rationale

Following the initial design system rollout in Milestone 42, comprehensive manual inspection and user review revealed several layout and stylistic discrepancies:
1. **Sidebar Collapse Failure**: The sidebar dock didn't collapse completely; hovering or clicking near the dock triggered a `:hover` rule (`.sidebar-dock:hover { width: var(--dock-expanded-w); }`), trapping the user and causing horizontal overflow.
2. **One-Way Top Bar Trap**: The shell switcher was only located in the sidebar footer. Once switched to Top Bar mode, the sidebar was hidden (`display: none`), leaving the user trapped with no way to return to Sidebar mode. Furthermore, duplicate tab navigation links remained visible in the main viewport during sidebar mode.
3. **Legacy Tailwind Blue Resurgence**: Saturated Tailwind blues (`#3b82f6`, `#2563eb`, `#1d4ed8`, `#60a5fa`, `#38bdf8`, `#0ea5e9`, `#93c5fd`, and `.badge.blue`) remained in default CSS badge classes and JavaScript-generated SVGs, violating the Warm Camel / Editorial palette.
4. **Emoji Soup**: Raw emojis (`🤖`, `💡`, `⏱`, `🔍`, `⚡`, `⚠️`, `🐝`, `🛠`, `📈`, `⚖`, `📋`, `💾`, `📁`, `⚙`, `🎯`, `🌿`) persisted in archetype cards, table headers, status pills, and buttons instead of unified Phosphor SVG icons.

---

## 2. Key Changes & Deliverables

### A. True 0px Complete Sidebar Collapse
- Removed `.sidebar-dock:hover` auto-expansion CSS trap.
- Introduced `.shell-mode-side.sidebar-collapsed` with complete 0px collapse (`transform: translateX(-100%); width: 0; opacity: 0; pointer-events: none;`).
- Main viewport smoothly expands to 100% full width (`margin-left: 0 !important`).
- Header `#btn-sidebar-toggle` and dock footer `#btn-sidebar-collapse-footer` provide explicit, synchronized click toggling with `localStorage.antigravity_sidebar_collapsed` persistence.

### B. Bidirectional Header Layout Switcher & Zero Duplicate Tabs
- Added `#header-shell-toggle` segmented control (`◧ Sidebar | ◫ Top Bar`) directly into the persistent top header.
- Added `.workspace-command-strip` class to `<div class="tab-nav">`.
- Enforced strict CSS tab suppression:
  - In Sidebar mode: `.shell-mode-side .workspace-command-strip .tab-buttons-group { display: none !important; }`
  - In Top Bar mode: `.shell-mode-top .workspace-command-strip .tab-buttons-group { display: flex !important; }`

### C. 100% Blue Purge Across CSS & JS
- Purged all instances of `#3b82f6`, `#2563eb`, `#1d4ed8`, `#60a5fa`, `#38bdf8`, `#0ea5e9`, `#93c5fd`, and `.badge.blue`.
- Default `.badge` rebound from blue to neutral surface tokens (`var(--surface-card)` / `var(--text-secondary)`).
- Swarm DAG SVG marker arrowheads and root nodes rebound to Warm Camel (`#D4A373`).
- Dynamic cache grading mapped to Emerald (`>=80%`), Warm Camel (`50-80%`), and Amber (`<50%`).

### D. Phosphor SVG Iconography & Zero Raw Emojis
- Replaced all raw unicode emojis with inline Phosphor SVG icons across `dashboard/index.html` and `dashboard/demo.html`.
- Cleaned dynamic string injections in `dashboard/app.js` to ensure zero emoji leakage into the DOM.

### E. Static Demo Parity & Live Telemetry Verification
- Synchronized `dashboard/demo.html` with `index.html` via `scripts/build_demo_showcase.py`.
- Refreshed authentic telemetry export with `python3 scripts/export_dashboard.py`.
- Re-verified watcher LaunchAgent daemon status (`RUNNING / REGISTERED`, PID 81100).
