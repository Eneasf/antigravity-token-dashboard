# Milestone 42.2: Layout Defect Elimination, Interactive Button Resilience & Persistent Icon Dock Rail

**Active Branch**: `feat/m42.2-fix-layout-and-buttons`  
**Standard**: Done if proven, not if declared (`AGENTS.md` §3 & `vdone`)

## 1. Context & Root Cause Analysis

Following the deployment of Milestone 42.1, thorough manual testing and user review uncovered three critical defects:
1. **Uncaught TypeError Crashing All Header Buttons**: In `dashboard/app.js` (`renderWeeklyTrendsSvg()`), `const cursorLine = svg.getElementById("trendline-cursor-line");` threw `TypeError: svg.getElementById is not a function` because `getElementById` only exists on `Document`, not `SVGElement`. This crashed `initDashboard()` midway during initialization, preventing event listeners from attaching and leaving Currency (`GBP/USD`), Theme (`Light/Dark`), and Shell Switcher (`Sidebar/Top Bar`) buttons unresponsive.
2. **Sidebar Disappearing Completely to 0px**: The previous collapse implementation translated the sidebar `-100%` off-canvas, vanishing completely. Per the Canonical Eneas Design System (`design-standards` Pattern A), the collapsed sidebar must be a **64px persistent vertical icon rail** with centered icons, never a 0px disappearing act.
3. **Horizontal Scrollbar Overflow**: The main viewport had `margin-left: 240px` combined with unconstrained flex basis inside a 100vw layout container. This pushed the viewport rightwards by 240px, creating horizontal scrolling. In addition, RGB blue remnants were identified in the What-If simulator, 5h burst governor, and weekly runway card.

---

## 2. Key Changes & Deliverables

### A. JavaScript Runtime Crash Fix & Direct Window Method Exposure
- Fixed `svg.getElementById("trendline-cursor-line")` to `document.getElementById("trendline-cursor-line")` in `renderWeeklyTrendsSvg()`.
- Added explicit, bulletproof controller functions: `setCurrency(curr)`, `setTheme(theme)`, `setShellMode(mode)`, `toggleSidebarExpand()`.
- Exposed all control functions on `window` and wired inline `onclick` handlers across `dashboard/index.html` and `dashboard/demo.html`.
- Attached `window.activeCurrency` and `window.activeTheme` properties for state inspection and testing.

### B. Persistent 64px Collapsed Icon Rail (Pattern A Standard)
- Sidebar dock in Sidebar mode defaults to a **64px icon dock rail** (`--dock-collapsed-w: 64px`).
- In collapsed mode: brand text and labels are hidden, and icons are centered with active indicators.
- Toggling `.sidebar-expanded` smoothly animates the dock width to 240px (`--dock-expanded-w`), revealing navigation labels, brand text, and chevron flip.
- In Top Bar mode (`shell-mode-top`), the sidebar dock is hidden (`display: none !important`) and top command strip tab buttons appear.

### C. Zero Horizontal Overflow & Viewport Sizing Constraints
- Added `overflow-x: hidden; max-width: 100vw;` to `html, body` and `.app-layout`.
- Constrained `.main-viewport` width to `calc(100% - var(--dock-collapsed-w))` in collapsed mode and `calc(100% - var(--dock-expanded-w))` in expanded mode.
- In Top Bar mode, `.main-viewport` takes full width (`margin-left: 0 !important; width: 100% !important;`).
- Added `min-width: 0; flex: 1 1 320px;` to `.title-group` and `justify-content: flex-end;` to `.badges`.

### D. Complete Blue Purge Across CSS & HTML
- Replaced all RGB blue instances (`rgba(37, 99, 235, ...)`, `rgba(14, 165, 233, ...)`) with Warm Camel tokens (`rgba(212, 163, 115, ...)`).
- Replaced `var(--accent-blue)` with `var(--camel-500)` or `var(--border-focus)` across simulator archetype cards, sliders, swarm lineage cards, burst sessions list, and trends KPIs.
- Removed sky-blue border on `provider-card-runway` in favor of `var(--card-border)`.
- Defined `--accent-mint` and `--accent-red` in `:root` and Light Mode legacy variable bridges.

### E. Static Demo Parity & Live Pipeline Verification
- Synchronized `dashboard/demo.html` with `index.html` to achieve 100% DOM parity.
- Rebuilt demo showcase via `python3 scripts/build_demo_showcase.py`.
- Re-exported authentic telemetry via `python3 scripts/export_dashboard.py`.
- Restarted and verified LaunchAgent daemon (`python3 scripts/setup_service.py restart && status`).
